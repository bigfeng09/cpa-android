# v0.5.0

## AI 供应商管理

- 新增“更多 > AI 供应商”页面，读取 CLI Proxy API 管理中心的供应商配置。
- 支持查看供应商类型、Base URL、前缀、优先级、API Key 数量和模型数量。
- 支持编辑基础字段、模型别名、自定义请求头、API Key 代理地址。
- 支持删除供应商，并在执行前显示确认提示。
- API Key 在页面中始终脱敏显示；编辑已有密钥时留空即可保留原值。
- 供应商保存仅提交对应配置数组，并保留服务器返回的未编辑字段。
